Logic Explanation

The loot array stores each item as an object. Every object has a name and a value, so the program can keep all the loot together while the page is open.

A traditional for loop goes through the array to add each item's value and find the total. Another loop displays each item in the Loot List. The total is calculated from the array whenever it is needed, so there is only one source for the total.

if statements check that the loot name and value are valid before an item is added. When splitting, they also check that the party size is a whole number of at least one and that the array contains loot. If something is missing or invalid, a message appears on the page instead of opening an alert.
